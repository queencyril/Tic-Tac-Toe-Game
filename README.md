# Tic-Tac-Toe Game 🎮

A simple and interactive Tic-Tac-Toe game built with React.

## 🚀 Live Demo

[Play the Tic-Tac-Toe Game]
https://my-tac-toe-game.netlify.app/

## 🛠️ Built With

* React
* JavaScript
* HTML
* CSS
* Vite

## ✨ Features

* Two-player gameplay
* Players can customize their names
* Highlights the active player
* Displays each player's moves in the game log
* Detects winners
* Detects draws
* Restart game functionality

## 💻 Getting Started

To run this project locally:

```bash
npm install
npm run dev
```

Then open the local development URL provided in your terminal.

## 📌 Project

This project was built as a React practice project to strengthen my understanding of React state, props, event handling, and dynamic rendering.
